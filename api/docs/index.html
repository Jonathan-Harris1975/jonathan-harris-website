Public API

This site exposes a simple, read-only JSON catalogue so tools (including AI assistants) can discover the full list of titles.

Endpoints

  • /api/v1/books.json — full catalogue (array of 36 books)

Fields

  • id, title, slug, short, cover, tags, filter, keywords, buy_url

Example (truncated):

[
  {
    "id": 1,
    "title": "…",
    "slug": "…",
    "tags": ["…"]
  }
