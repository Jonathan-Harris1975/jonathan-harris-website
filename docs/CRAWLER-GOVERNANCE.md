# Crawler Asset Governance

## Canonical files

| Asset | Canonical path | Purpose |
|-------|---------------|---------|
| Robots | `/robots.txt` | Canonical robots directives, AI crawler allowances, and sitemap pointer |
| Sitemap | `/sitemap.xml` | Canonical sitemap — referenced from robots.txt and published as the only root sitemap file |

## Alias files (retained for compatibility)

| File | Status | Notes |
|------|--------|-------|
| `robot.txt` | Legacy alias | Some crawlers drop the trailing 's'. Identical content to robots.txt. |
| `Sitemap.xml` | Legacy alias | Capital-S variant retained as a redirect to `/sitemap.xml`. |
| `site-map.xml` | Legacy alias | Hyphenated variant retained as a redirect to `/sitemap.xml`. |

## Authoritative source

Crawler assets are generated by the ebook derivative pipeline and validated in `config/crawler-checksums.json`.
The canonical publication target for robots is `https://jonathan-harris.online/robots.txt`.
The canonical sitemap target is `https://jonathan-harris.online/sitemap.xml`.

Do not create duplicate alias files. Edit the canonical `sitemap.xml` source and re-run the crawler sync script.
